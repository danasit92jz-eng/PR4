# Data Analyzer and Transformer Using Python
## Project Overview
This project is a simple Python-based Data Analyzer and Transformer. It allows users to enter data in 1D and 2D lists and perform basic data analysis using Python functions.
## Objectives
- To understand Python built-in functions.
- To create and use user-defined functions.
- To understand `*args` and `**kwargs`.
- To perform basic data analysis.
- To work with 1D and 2D lists.
- To practice loops, conditions, and lambda functions.
## Features
- Input data using 1D lists.
- Input data using 2D lists.
- Calculate total elements, sum, minimum, maximum, and average.
- Find duplicate values.
- Find unique values.
- Use `*args` and `**kwargs` to pass multiple values.
- Apply basic data transformation and filtering.
- Sort data in ascending or descending order.
## Technologies Used
- **Programming Language:** Python
- **Concepts:** Lists, Functions, Loops, Conditional Statements, Lambda Functions
- **Tools:** Python IDLE

## Python Concepts Covered

| Concept | Description |
|---|---|
| Built-in Functions | `len()`, `sum()`, `min()`, `max()` |
| User-defined Functions | Creating and calling functions |
| `*args` | Passing multiple positional arguments |
| `**kwargs` | Passing multiple keyword arguments |
| Lambda Functions | Creating small anonymous functions |
| Lists | Storing and processing data |
| Loops | Repeating operations |
| Conditional Statements | Making decisions |

## How to Run the Project
1. Install Python on your computer.
2. Download or clone this repository.
3. Open the project folder in VS Code or Python IDLE.
4. Run the Python file:
   ```bash
   pr4.py
   ```
5. Select the required option from the menu.
6. Enter your data and view the results.

## Conclusion
This project demonstrates how Python functions and lists can be used to perform basic data analysis and transformation. It provides practical experience with built-in functions, user-defined functions, argument handling, and data processing.
